# hwh-presets-api

Готовые сборки для Архидемона, которые показывает дополнение [HWHArchdemonExt](https://github.com/nexgen-hw-dev/HWHArchdemonExt).
Функция на Netlify отдаёт их одним массивом.

```
GET https://<сайт>.netlify.app/api/v1/presets
```

Ответ — JSON-массив, без ключей и без данных игрока. CORS открыт всем (`Access-Control-Allow-Origin: *`): данные
публичные и только для чтения. Браузер и CDN Netlify держат ответ 2 часа, новый деплой сбрасывает кеш CDN.
Дополнение само хранит копию в `localStorage` 2 часа и при сбое сети берёт просроченную.

## Формат сборки

Одна сборка — массив, смысл поля задаёт его место:

| Место | Поле | Правило |
|---|---|---|
| 0 | ник автора | строка до 40 символов |
| 1 | тип видео | 0 — нет, 1 — YouTube |
| 2 | id видео | `"5ZlBvFy2xzw"` для YouTube, пустая строка, если видео нет |
| 3 | урон | в миллиардах, два знака после точки, лишнее отбрасываем: 10 818 491 942 → `10.81` |
| 4 | усиление | как в игре: 150, а не уровень Амулета 15 |
| 5 | монеты перед Архидемоном | 0 — неизвестно |
| 6 | талисманы | `[первая выдача, вторая выдача]`, например `[8008, 8003]` |
| 7 | основной питомец | коротко `8` = 6008 или полный номер |
| 8 | герои | подряд тройки `герой, ранг, покровитель`: `[46,1,0, 29,3,6, …]`. Ранг 1, 3 или 7. Покровитель 0 — нет |

Короткий номер питомца: число от 1 до 99 значит 6000 + n. **Fenris — это 6000**, коротко его не записать (0 значит
«нет покровителя»), пишем полностью: `67,1,6000`.

Что в данных не хранится, а зашито в дополнении:
- префиксы видео: 1 — `https://www.youtube.com/watch?v=`;
- источники для шапки списка: HWDaily (`https://hwdaily.win/`, автор Fragator) и HWMAP (`https://hwmap.online/`, автор Kircheis).

**Развитие формата.** Новые поля только дописываются в конец строки, смысл старых мест не меняется: старые сборки
дополнения лишнее пропускают. Несовместимое изменение — только новым адресом, `/api/v2/presets`.

Сборки текущего события. Кончилось событие — старые удаляем, началось новое — кладём новые. Сборку, чьи герои
или покровители не подходят текущему событию, дополнение не показывает: проверка та же, что у строки героев в окне.

## Как обновить

1. Правим `data/presets.json`.
2. `node tools/check.mjs` — форма данных, ранги, повторы героев и покровителей, одинаковые настройки.
3. Коммит и пуш. Netlify разворачивает сам.

## Откуда сборки

Составы из открытых видео игроков, собранные на [HWDaily](https://hwdaily.win/) и [HWMAP](https://hwmap.online/).
Ник автора и ссылка на видео — в каждой сборке.
