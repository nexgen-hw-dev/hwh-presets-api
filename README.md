# hwh-presets-api

Готовые сборки для Архидемона, которые показывает дополнение [HWHArchdemonExt](https://github.com/nexgen-hw-dev/HWHArchdemonExt).
Функция на Netlify отдаёт их одним массивом.

```
GET https://<сайт>.netlify.app/api/v1/presets
```

Тот же файл отдают ещё два зеркала — репозиторий публичный:

```
https://cdn.jsdelivr.net/gh/nexgen-hw-dev/hwh-presets-api@main/data/presets.json
https://raw.githubusercontent.com/nexgen-hw-dev/hwh-presets-api/main/data/presets.json
```

Дополнение пробует их по очереди — Netlify, jsDelivr, GitHub, — на каждое до 5 секунд, и запоминает ответившее.
Netlify обновляется сразу после деплоя, GitHub — через несколько минут, jsDelivr держит свой кеш до 12 часов.

Ответ — JSON-массив, без ключей и без данных игрока. CORS открыт всем (`Access-Control-Allow-Origin: *`): данные
публичные и только для чтения. Браузер и CDN Netlify держат ответ 2 часа, новый деплой сбрасывает кеш CDN.
Дополнение само хранит копию в `localStorage` 15 минут (с 1.17) и при сбое сети берёт просроченную.

## Формат сборки

Одна сборка — массив, смысл поля задаёт его место:

| Место | Поле | Правило |
|---|---|---|
| 0 | ник автора | строка до 40 символов; пустая — автор неизвестен |
| 1 | тип видео | 0 — нет, 1 — YouTube |
| 2 | id видео | `"5ZlBvFy2xzw"` для YouTube, пустая строка, если видео нет |
| 3 | урон | в миллиардах, два знака после точки, лишнее отбрасываем: 10 818 491 942 → `10.81` |
| 4 | усиление | как в игре: 150, а не уровень Амулета 15 |
| 5 | монеты перед Архидемоном | 0 — неизвестно |
| 6 | талисманы | `[первая выдача, вторая выдача]`, например `[8008, 8003]` |
| 7 | основной питомец | коротко `8` = 6008 или полный номер; 0 — без основного питомца |
| 8 | герои | подряд тройки `герой, ранг, покровитель`: `[46,1,0, 29,3,6, …]`. Ранг 1, 3 или 7. Покровитель 0 — нет |
| 9 | стратегия | необязательно, с HWHArchdemonExt 1.18: своя стратегия прогона, см. ниже. Нет — общая стратегия события. Есть глава, а стратегии нет — `null` |
| 10 | глава | необязательно, с HWHArchdemonExt 1.25: в какой главе снят урон — номер по порядку среди глав события с Архидемоном, с 1. Нет — глава неизвестна. Есть событие, а глава неизвестна — `0` |
| 11 | событие | необязательно, с HWHArchdemonExt 1.26: номер события, как `3029000034`. Нет — для любого события |

**Глава.** С 16.11.2026 Архидемон снова в конце каждой главы, и у каждой главы свой Архидемон и множитель урона: урон
одной и той же сборки в разных главах не сравнить. Дополнение показывает в окне сборки той главы, что выбрана в окне
настройки, и сборки без главы. Версии до 1.25 одиннадцатое поле не читают.

**Событие.** Номера глав у событий одни и те же, а Архидемоны разные: 16.11.2026 идёт Roots of Destiny `3029000034`,
а 23.11 сразу за ним `3941000034`. С номером события дополнение показывает сборку только в своём событии, поэтому
сборки следующего события можно выложить заранее, а не менять файл в момент смены. Версии до 1.26 двенадцатое поле
не читают и показывают все сборки подряд.

Короткий номер питомца: число от 1 до 99 значит 6000 + n. **Fenris — это 6000**, коротко его не записать (0 значит
«нет покровителя»), пишем полностью: `67,1,6000`.

## Стратегия прогона

С HWHArchdemonExt 1.18 сборка под Эмблему капитала идёт по стратегии: кто проходные и до какого ранга, кем и на
какой точке сливать, а с 1.25 — ещё для каких глав, брать ли неизвестные карты на точке 1 и сколько обновлений
можно потратить. Формат один для стратегии сборки и общей стратегии события:

```json
{ "buff": [150, 199], "carry": [46, 1, 72, 1], "sacrifice": 46, "point": 5, "chapters": [5, 6], "cards": "cheap", "reserve": 3, "refreshes": 2 }
```

| Поле | Правило |
|---|---|
| `buff` | усиление игрока от и до, включительно, 0–1000 |
| `carry` | проходные парами `герой, ранг`, от одного до пяти, без повторов; ранг 1, 3 или 7 |
| `sacrifice` | кем сливать: номер героя или список до пяти — берётся первый, кто есть |
| `point` | на какой точке сливать: номер от 1 до 20, с 1.23 любая обычная точка главы — не главный босс и не Архидемон; нет такой в главе — ближайшая раньше. До 1.23 — только 5 или 7 |
| `chapters` | необязательно, с 1.25: для каких глав стратегия, номера по порядку без повторов. Нет — для любой |
| `cards` | необязательно, с 1.25: неизвестные карты на точке 1 — `none` не брать, `cheap` только дешевле своей продажи (две такие зарабатывают обновление лавки), `any` все. Нет — `none` |
| `reserve` | необязательно, с 1.25: запас обновлений лавки на точке 1, 0–30. Нет — 0 |
| `refreshes` | необязательно, с 1.25: обновлений лавки ради героя для слива, 0–30. Нет — 0 |
| `ascend` | необязательно, с 1.27: кого возвысить, если взята Эмблема возвышения, — до пяти героев без повторов, по порядку. Перед Архидемоном прогон возвышает их, если они собраны полностью (7 фрагментов), по 30 монет, пока монет не меньше минимума под капитал. Нет — герои состава сборки. Версии до 1.27 поле не читают |

- **Своя стратегия сборки** — десятое поле строки (место 9). Берётся, если усиление игрока в её диапазоне, а глава
  окна настройки — в её списке глав (если список есть).
- **Общая стратегия события** — поле `strategy` элемента события, см. ниже:
  `{ "event": 3029000034, "strategy": [ {…до 199…}, {…от 200…} ] }`. Берётся первая, чей диапазон покрывает
  усиление игрока и чей список глав — главу окна настройки. В главах с Архидемоном в конце у каждой главы и каждого
  усиления свои проходные, поэтому стратегию удобно делить по `chapters` и `buff`.
  Версии дополнения до 1.18 считают этот элемент испорченной строкой и пропускают, версии до 1.25 — новые поля.
- Нет ни той, ни другой — стратегия, встроенная в дополнение (`NX_BUILTIN_STRATEGIES`). С 1.26 она своя у каждого
  события и есть только у Бездны `3032000034` (Марта и Бирна); у Приключений 16.11 и 23.11.2026 встроенной нет.
  Сборку под капитал без стратегии дополнение 1.26 не запускает: «Поехали» скажет, что стратегии для этой главы
  и усиления нет. До 1.26 встроенная — правила `3032000034` — бралась в любом событии.

Каждую стратегию дополнение проверяет по точке 1 главы: проходных, которых к ней не взять (не стартовые герои главы
и нет в постоянных лотах первой лавки), — берёт следующую. Поэтому общая стратегия — под стартовых героев события.

## Элемент события

С HWHArchdemonExt 1.26 в том же массиве, кроме сборок, бывают объекты — элементы события, обычно первыми:

```json
{ "event": 3029000034, "strategy": [ … ], "sites": [{ "name": "HWMAP", "url": "https://hwmap.online/invasion/3029000034/teams" }] }
```

| Поле | Правило |
|---|---|
| `event` | номер события. Нет поля — элемент для любого события |
| `strategy` | общая стратегия события, см. выше |
| `sites` | ссылки для шапки окна сборок, от одной до четырёх `{ name, url }`: название сайта до 40 символов и адрес `https` |

Нужно хотя бы одно из `strategy` и `sites`. Элемент с номером идущего события главнее элемента без номера, поле
за полем: нет в нём ссылок — ссылки из элемента без номера. Элемент чужого события не берётся. На событие — один
элемент, и один без номера. Нет ссылок ни там, ни там — в шапке главные страницы HWDaily и HWMAP. Подпись
у ссылки — по названию: у `HWDaily` и `HWMAP` своя, у другого сайта подписи нет.

Версии до 1.26: элемент без `strategy` считают испорченной строкой и пропускают, номер события не читают и берут
стратегию последнего элемента, где она есть, — пока игроки не перешли на 1.26, общую стратегию держим одну.
Ссылки в шапке у них свои, зашитые в версию: в 1.10–1.25 — страницы события `3032000034`.

Что в данных не хранится, а зашито в дополнении: префиксы видео, 1 — `https://www.youtube.com/watch?v=`.

**Развитие формата.** Новые поля только дописываются в конец строки, смысл старых мест не меняется: старые сборки
дополнения лишнее пропускают. Несовместимое изменение — только новым адресом, `/api/v2/presets`.

Сборки событий: кончилось событие — его сборки удаляем. С номером события сборки следующего можно выложить заранее,
но версии до 1.26 покажут их и в идущем событии. Сборку, чьи герои или покровители не подходят текущему событию,
дополнение не показывает: проверка та же, что у строки героев в окне.

## Как обновить

1. Правим `data/presets.json`.
2. `node tools/check.mjs` — форма данных, ранги, повторы героев и покровителей, одинаковые настройки, стратегии, главы,
   события и их элементы, ссылки.
3. Коммит и пуш. Netlify разворачивает сам.
4. Сбросить кеш jsDelivr, иначе через него старые сборки будут видны до 12 часов: открыть в браузере
   `https://purge.jsdelivr.net/gh/nexgen-hw-dev/hwh-presets-api@main/data/presets.json`.

## Откуда сборки

Составы из открытых видео игроков, собранные на [HWDaily](https://hwdaily.win/) и [HWMAP](https://hwmap.online/).
Ник автора и ссылка на видео — в каждой сборке.
